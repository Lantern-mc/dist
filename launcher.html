Lantern 런처로 서버에 들어가기

들어갈 서버의 웹 패널에서 서버 들어가기를 누르면 런처가 모드팩을 설치하고 서버에 접속합니다.

시작하기 전에

서버 웹 패널 주소

Lantern 서버는 서버마다 자기 웹사이트(웹 패널)가 있습니다. 주소는 서버 운영진에게 받으세요.

Windows

Windows용 프로그램입니다.

CurseForge 앱

모드팩은 CurseForge 앱으로 설치합니다. 게임 실행은 런처가 합니다.

마이크로소프트 계정

마인크래프트 자바 에디션을 소유한 계정으로 로그인합니다.

화이트리스트 확인

화이트리스트를 쓰는 서버에서는 로그인한 마이크로소프트 계정의 닉네임과 UUID로 서버가 목록에 있는지 확인합니다. 로그아웃 상태에서는 확인을 할 수 없고, CurseForge로 실행으로 확인 없이 진행할 수 있습니다.

런처 받기

관리자 권한 없이 설치됩니다.

런처 받기
  • SmartScreen — Windows가 서명 없는 파일이라 Windows의 PC 보호 창을 띄울 수 있습니다. 추가 정보 → 실행으로 설치를 이어가세요.
  • 파일 확인 — PowerShell Get-FileHash로 내려받은 실행 파일의 SHA-256을 릴리스에 함께 올라온 해시 파일 첫 줄과 비교할 수 있습니다.
  • 제거 — Windows 설정 › 앱에서 Lantern을 제거합니다. CurseForge 프로필은 그대로 남습니다.

처음 실행할 때

  1. CurseForge 앱이 설치돼 있는지 확인합니다.
  2. 마이크로소프트 계정으로 로그인합니다.
  3. 운영진에게 받은 서버 웹 패널 주소로 들어가 Discord로 로그인하고, 서버 들어가기를 누른 뒤 런처 창에서 연결을 허용합니다.
  4. 런처가 모드팩을 설치·맞춥니다.
  5. 게임 실행으로 서버에 들어갑니다.
