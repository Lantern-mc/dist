파일과 서버 설정

파일 화면으로 서버 폴더를 다루고, 설정의 서버·게임 규칙·성능·위험에서 패널이 지원하는 항목을 바꿉니다.

파일 관리자

섹션 제목: “파일 관리자”

파일 목록은 서버 폴더부터 하위 경로로 내려갑니다. 이 폴더에서 찾기, 새 폴더, 올리기, 끌어다 놓기, 이름 바꾸기, 삭제, 받기를 씁니다. 편집기에서 저장·수정됨 표시가 있습니다.

서버가 켜져 있을 때 쓰기 제한

섹션 제목: “서버가 켜져 있을 때 쓰기 제한”

서버 상태가 꺼져 있어요 또는 비정상 종료(crashed)가 아니면 다음은 쓸 수 없습니다(409).

  • server.properties, whitelist.json, ops.json, banned-players.json, banned-ips.json
  • 월드 폴더(오버월드·네더·엔드)

백업·복원·설치 작업 중에도 쓰기가 막힙니다. 로그 파일은 읽기 전용입니다.

비밀값 가리기

섹션 제목: “비밀값 가리기”

server.properties의 password·secret·token류, 로그의 비슷한 줄, RCON·Discord·CurseForge 키 형태는 편집·다운로드·표시 시 *** 등으로 가려집니다. 편집기에서 ***로 두면 저장 시 기존 값을 유지합니다. server.properties를 파일 화면에서 열면 다음 재시작부터 적용 · 서버 설정 화면과 같은 값 안내가 있습니다.

서버 설정(패널)

섹션 제목: “서버 설정(패널)”

설정 → 서버 (기본 정보): 서버 이름, MOTD, 게임 접속 주소, 최대 인원, 포트. 화이트리스트는 플레이어 화면 안내와 같습니다.

게임 규칙: 난이도, 기본 게임 모드, 하드코어, 명령 블록, 지금 서버의 규칙(켜져 있을 때 일부 gamerule), 시야 거리·시뮬레이션 거리, 스폰 보호. 서버가 값을 거부하면 서버가 값을 바꾸지 않았습니다가 나올 수 있고, 다시 시작해야 적용됩니다일 때 지금 다시 시작을 씁니다.

성능 (메모리와 CPU): Java 메모리, 사용할 CPU 코어, 멈추면 다시 켜기, JVM 튜닝, 추가 JVM 인자(힙 -Xmx/-Xms는 슬라이더만). 서버-만들기에서 정한 값과 같은 항목입니다.

월드 리셋·서버 초기화

섹션 제목: “월드 리셋·서버 초기화”

설정 → 위험 (world.destroy 권한):

작업 내용
월드 리셋 설정과 모드는 그대로 둡니다. 선택 시드 가능. 실행 전 월드 백업
서버 초기화 월드·모드·설정을 모두 지웁니다. 서버 폴더 전체 백업 후 삭제

두 작업 모두 확인 창에서 서버 이름을 정확히 입력해야 합니다. 서버가 켜져 있어 먼저 중지합니다. 월드 리셋 백업(pre_change)은 백업과-복원 화면에서 복원할 수 있습니다. 서버 초기화 백업(pre_reset_full)만 원클릭 복원 버튼이 없고, 같은 화면에서 파일로 받을 수 있습니다.

관련 문서

섹션 제목: “관련 문서”
  • 모드·config jar: 모드와-CurseForge
  • 콘솔 명령·gamerule 실시간: 콘솔과-부팅-진단
  • 감사: 감사-로그 (files.write, files.write_secret)
