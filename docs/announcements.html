공지와 알림

랜딩 공지 · 인사말에서 인사말·공지·표시 옵션을 다루고, 알림에서 운영·개인 알림을 봅니다.

인사말

섹션 제목: “인사말”

인사말은 최대 120자까지 저장하며, 랜딩에서는 서버 이름 아래 2줄까지 보입니다. 저장됨 상태가 되면 반영됩니다.

공지 작성·게시

섹션 제목: “공지 작성·게시”
  1. 새 공지 또는 편집을 엽니다.
  2. 제목, 본문, 게시 시작, 끝나는 날, 보이는 역할(플레이어 · 손님 등)을 정합니다.
  3. 랜딩 맨 위에 고정, Discord 채널에도 올리기를 필요에 따라 켭니다.
  4. 게시 또는 저장합니다.

상태는 게시 중 · 예약 · 내림입니다. 내리기·다시 올리기로 노출을 바꿀 수 있습니다. Discord는 공지 채널이 정해져 있고 봇이 켜져 있어야 하며, 실패 시 다시 시도·Discord에 올리기로 재전송합니다. 공지 쓰기 권한이 필요합니다.

랜딩 표시 옵션

섹션 제목: “랜딩 표시 옵션”

랜딩 표시에서 끄고 켤 수 있는 블록:

  • 공지
  • 월드 소식(월드 나이·플레이 시간)
  • 업데이트 배지(모드팩 갱신)
  • 손님 다운로드
  • 최근 소식(접속·종료 등)

알림 종류

섹션 제목: “알림 종류”

패널 알림 설정(설정)에 나열된 종류 예:

종류 대상(권한) 설명
화이트리스트 신청 화이트리스트 승인 · 추가 · 빼기 누군가 화이트리스트를 신청했을 때
내 신청 결과 화이트리스트 신청 내 신청 승인·거절
서버 멈춤 시작 · 재시작 멈춤·자동 재기동
자원 경고 시작 · 재시작 메모리·디스크·TPS
백업 실패 / 백업 완료 백업 만들기 · 받기 자동 백업 결과
시스템 백업 실패 역할 편집 · 브랜딩 · 시스템 설정 시스템 상태 백업
서버 켜기 요청 시작 · 재시작 켤 권한 없는 멤버의 요청
서버 켜짐 서버 상태와 접속자 꺼져 있다가 켜졌을 때(기본 패널 알림 꺼짐)
런처 프로필 코드 만료 임박 파일 수정 · 모드 관리 CurseForge 프로필 코드

채널과 조용한 시간

섹션 제목: “채널과 조용한 시간”

각 종류마다 패널 · 브라우저 · Discord DM을 켤 수 있습니다. Discord DM은 봇이 연결되어 있을 때만 가능합니다(Discord DM은 봇이 연결되면 쓸 수 있습니다.).

밤 시간엔 조용히에 시작·끝 시각을 넣으면 그 시간에는 브라우저·DM 알림을 보내지 않습니다. 조용한 시간에는 브라우저·DM 알림을 보내지 않습니다.

보관

섹션 제목: “보관”

알림은 30일 지난 항목과 멤버당 최신 200건을 넘는 오래된 항목을 정리합니다.
