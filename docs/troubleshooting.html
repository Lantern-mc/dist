문제 해결

자주 만나는 경우를 모았습니다. 질문을 눌러 펼치세요.

설치가 실패했습니다

섹션 제목: “설치가 실패했습니다”

홈 화면에 이 서버에 문제가 있습니다 카드가 나오고, 아래에 이유가 적힙니다. 카드의 버튼은 이렇게 씁니다.

  • 다시 시도: 같은 설치를 다시 합니다. 네트워크가 잠깐 끊긴 경우에 가장 먼저 해 볼 것입니다.
  • 기존 CurseForge 인스턴스 연결…: 이미 CurseForge에 이 모드팩 프로필이 있다면 그것을 런처에 연결합니다.
  • 웹 패널 열기: 서버 웹 패널로 가서 서버 들어가기를 다시 누를 때 씁니다.

게임이 시작되지 못한 경우에는 로그 폴더 열기 버튼이 함께 나옵니다.

서버가 꺼져 있다고 나옵니다

섹션 제목: “서버가 꺼져 있다고 나옵니다”

서버가 꺼져 있거나 연결할 수 없습니다는 서버가 아직 켜지지 않았거나 일시적인 네트워크 문제가 있을 수 있다는 뜻입니다. 접속이 실패할 수 있습니다. 잠시 뒤 더보기의 지금 확인으로 상태를 다시 보세요. 계속 꺼져 있으면 서버 운영진에게 알려 주세요.

접속 불가나 패널 응답 없음은 서버 쪽에서 확인해야 하는 상태입니다.

화이트리스트에 없다고 나옵니다

섹션 제목: “화이트리스트에 없다고 나옵니다”

내 닉네임이 서버 화이트리스트에 없다는 뜻입니다. 서버 운영진에게 등록을 신청하세요. 승인 대기 중이라면 신청은 된 상태이니 승인을 기다리면 됩니다. 기다리는 동안에도 그래도 실행으로 게임을 켤 수는 있지만 접속은 거부될 수 있습니다.

SmartScreen이 실행을 막습니다

섹션 제목: “SmartScreen이 실행을 막습니다”

최초 설치 때 Windows의 PC 보호 창이 뜨면 추가 정보를 누른 뒤 실행을 누르세요. 자세한 순서는 설치 페이지에 있습니다.

CurseForge 앱을 찾지 못합니다

섹션 제목: “CurseForge 앱을 찾지 못합니다”

CurseForge 앱이 필요합니다가 나오면 CurseForge 받기로 CurseForge 앱을 설치하고, 설치가 끝난 뒤 다시 확인을 누르세요. 이미 설치했는데도 찾지 못하면 설정의 CurseForge 항목에서 변경으로 위치를 알려 줄 수 있습니다.

게임이 시작하자마자 꺼집니다

섹션 제목: “게임이 시작하자마자 꺼집니다”

“게임이 곧바로 종료되었습니다”라는 안내가 나옵니다. 모드 충돌이나 메모리 부족일 수 있습니다. 설정의 최대 메모리를 늘려 보거나, 설치를 다시 시도하세요.

로그인이 안 됩니다

섹션 제목: “로그인이 안 됩니다”

마인크래프트 자바 에디션을 가진 마이크로소프트 계정이어야 합니다. 자녀 계정이라면 Microsoft 패밀리 설정에서 보호자가 온라인 플레이를 허용해야 합니다. 로그인 창은 닫으면 취소되니, 브라우저에서 끝낸 뒤 이 창이 자동으로 닫히는 것을 기다리세요.

연결 코드가 만료되었다고 나옵니다

섹션 제목: “연결 코드가 만료되었다고 나옵니다”

연결 코드는 한 번만 쓸 수 있고 시간이 지나면 만료됩니다. 웹 패널에서 서버 들어가기를 다시 누르면 새 코드가 만들어집니다.

로그는 어디에 있나요

섹션 제목: “로그는 어디에 있나요”

런처의 기록은 %LOCALAPPDATA%\Lantern\Launcher\tray.log에 남습니다. 경로를 외우지 않아도 설정의 로그 폴더 열기를 누르면 그 폴더가 열립니다.

도움을 요청하려면

섹션 제목: “도움을 요청하려면”

서버를 운영하는 분이나 그 서버의 도움 채널에 문의하세요. 아래를 함께 알려 주면 빨리 풀립니다.

  • 런처 버전(설정의 정보에 나오는 현재 버전)
  • 무엇을 눌렀고 어떤 메시지가 나왔는지(화면 캡처)
  • tray.log의 마지막 부분

로그에는 PC의 폴더 이름이 들어 있을 수 있으니, 공개된 곳에 올리기 전에 사용자 이름 같은 개인 정보를 지우세요.

Lantern Launcher는 Lantern 서버에 들어가기 위한 Windows용 프로그램입니다. Mojang, Microsoft, CurseForge와 관련 없는 독립 프로젝트이며, Minecraft와 CurseForge는 각 권리자의 상표입니다.
