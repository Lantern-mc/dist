Discord 연결

Lantern은 Discord OAuth로 로그인하고, 봇으로 길드 멤버·역할·알림·화이트리스트 신청 카드를 처리합니다. 커뮤니티 Discord 서버 하나에만 연결하는 전제입니다.

Discord 애플리케이션 만들기

섹션 제목: “Discord 애플리케이션 만들기”
  1. Discord Developer Portal에서 새 앱을 만듭니다.
  2. Bot 메뉴에서 봇을 켭니다.
  3. Bot › Privileged Gateway Intents에서 Server Members Intent를 켭니다. 역할 목록·멤버 동기화에 필요합니다(설정 화면 문구: 멤버 목록을 읽을 수 있음).
  4. OAuth2 › Redirects에 패널 주소 기준 https://<패널-도메인>/api/auth/callback을 넣습니다. 이 주소를 OAuth2 › Redirects에 넣기 안내와 같아야 합니다.

로그인 scope는 identify만 요청합니다(backend/lantern/discord/rest.py). Discord 이름과 길드 멤버십·역할만 쓰며, 메시지나 다른 서버 정보는 읽지 않습니다(로그인 화면 Discord로 계속하기 설명).

패널에 넣을 값

섹션 제목: “패널에 넣을 값”

처음에는 /setup, 이후에는 설정 › Discord 또는 설정 › 패널에서 같은 항목을 고칩니다.

항목 용도
설정 코드 첫 설정·복구 시 컨테이너 로그의 코드. Discord 연결 저장 후 입력칸이 잠깁니다
애플리케이션 ID OAuth 클라이언트 ID
클라이언트 시크릿 OAuth 시크릿
봇 토큰 Gateway 봇 로그인
이 패널의 웹 주소 OAuth Redirect 계산용 공개 HTTPS URL

연결 확인 / 연결 다시 확인이 다음을 검사합니다.

  • 앱 정보가 맞음 — ID와 봇 토큰이 같은 앱인지
  • 봇 로그인됨
  • 봇이 서버에 있음 — 봇 초대하기 링크로 길드에 초대
  • 멤버 목록을 읽을 수 있음 — Server Members Intent

봇이 들어 있는 길드가 하나면 자동으로 연결되고, 여러 개면 연결할 Discord 서버를 고른 뒤 이 서버로 연결합니다. 연결된 서버: … 로 표시됩니다.

이 패널의 웹 주소와 브라우저 주소가 다르면 이 패널을 …에서 열어 설정하세요 경고가 납니다.

로그인과 관리자

섹션 제목: “로그인과 관리자”

이 브라우저로 Discord 로그인으로 OAuth를 마치면, 그 세션의 Discord 계정이 첫 관리자가 됩니다. 길드에 없는 계정은 우리 Discord 멤버만 들어올 수 있어요로 거절됩니다.

패널 주소를 바꾸면 Discord 개발자 포털 Redirects에 새 …/api/auth/callback을 먼저 등록해야 합니다(주소를 바꾸면 Discord 개발자 포털의 Redirects에 … 경고).

봇이 하는 일

섹션 제목: “봇이 하는 일”

Discord DM

섹션 제목: “Discord DM”

알림 설정에서 종류별로 Discord DM 채널을 켤 수 있습니다. 봇이 온라인일 때만 Discord DM은 봇이 연결되면 쓸 수 있습니다가 해제됩니다. 조용한 시간 설정은 브라우저·DM에만 적용됩니다.

공지·채널

섹션 제목: “공지·채널”

설정 › Discord에서 텍스트 채널을 지정합니다.

  • 상태·요청·공지·채팅용 채널 ID
  • 공지 올리기로 공지 채널에 게시
  • 채팅 연동을 켜면 마인크래프트 채팅과 Discord 채널을 연결합니다. Discord 개발자 포털에서 Message Content Intent를 켜야 합니다

요청 채널에는 화이트리스트 신청 카드와 스레드가 생깁니다. 운영자는 카드에서 승인·거절할 수 있습니다.

슬래시 명령

섹션 제목: “슬래시 명령”

길드 전용 슬래시 명령(한국 Discord 클라이언트 기준 표시 이름):

명령 설명
상태 서버 상태
켜기 꺼진 서버 켜기(권한 있을 때)
백업 백업 만들기(권한 있을 때)
월드리셋 월드 삭제 후 새로 만들기(권한·확인 절차 있음)
신청 닉네임 인자로 화이트리스트 신청

개인에게 보이는 응답은 Discord 클라이언트 언어, 없으면 패널 locale, 없으면 봇 언어(한국어 / English) 순입니다.

역할

섹션 제목: “역할”

역할과 권한에서 Discord 역할을 운영자·플레이어 카드에 연결합니다. 봇이 역할 목록을 가져오지 못하면 Discord 역할 ID (쉼표로 구분) 입력으로 대체됩니다.

문제 해결

섹션 제목: “문제 해결”
증상 확인
봇 로그인 실패 봇 토큰 재복사, 토큰 재발급 후 연결 다시 확인
봇이 서버에 없음 봇 초대하기, 봇에 길드 접근 권한
멤버 목록을 못 읽음 Server Members Intent, 봇 재초대
Discord와 연결하지 못했어요 Redirect URL·패널 주소·HTTPS
우리 Discord 멤버만… 사용자가 Discord 서버에 가입했는지
로그인 직후 모두 손님 Discord 역할 연결이 아직 없음. 역할과 권한 또는 멤버 화면에서 역할 지정
채팅 연동 무반응 Message Content Intent, 채팅 채널 선택

봇 연결이 끊기면 설정 › Discord 또는 시스템 화면에서 Discord 봇 다시 연결을 쓸 수 있습니다.

Discord 연결을 잃었을 때: docker compose exec lantern lantern recover → 새 설정 코드로 키만 다시 넣고 관리자 재지정.

관련: 설치하기, 공지와 알림, 플레이어와 화이트리스트.
