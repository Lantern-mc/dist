모드와 CurseForge

모드 화면에서 서버 jar 모드를 올리고, CurseForge에서 추가하며, 모드팩 단위로 바꿉니다. 바닐라·Paper 서버는 **이 서버는 모드를 쓰지 않는 종류(바닐라 또는 Paper)입니다.**로 모드 기능이 없습니다.

서버 모드 목록

섹션 제목: “서버 모드 목록”

설치된 모드 표에서 모드, 버전, 출처(직접 추가 / 모드팩), 켜기 토글, 삭제를 씁니다. 서버 모드 올리기로 .jar를 올립니다. 모드를 바꾼 내용은 서버를 다시 켠 뒤에 적용됩니다. 실행 중에 켜지는 중이면 서버가 이미 켜지는 중이라 모드를 바꾸지 못했어요가 날 수 있습니다.

필터: 전체, 직접 추가, 꺼짐, 클라이언트 전용.

CurseForge에서 추가

섹션 제목: “CurseForge에서 추가”

CurseForge에서 모드 추가에서 검색 후 추가합니다. CurseForge API 키(선택)가 필요합니다. 시스템 설정에서 넣으세요 — 키는 선택이며, 서버 만들기의 서버팩 zip 올리기 설치에는 필요 없습니다(오류 문구와 시스템 설정의 CurseForge 안내와 동일).

배포가 막힌 모드는 배포 막힘 · 직접 받아야 함으로 표시됩니다. 추가 시 CurseForge API가 알려 주는 필요 의존 모드는 서버가 자동으로 받습니다(깊이·개수에 상한 있음). 일부는 **CurseForge 모드 추가: … (의존성: …)**처럼 감사 로그에 남습니다.

클라이언트 전용 모드

섹션 제목: “클라이언트 전용 모드”

클라이언트 전용으로 표시된 모드 N개가 켜져 있어요 배너가 있으면 모두 끄기로 한꺼번에 끌 수 있습니다. 콘솔과 부팅 진단의 부팅 진단과도 연결됩니다.

모드 삭제

섹션 제목: “모드 삭제”

모드 삭제에서 삭제를 입력해 확인합니다. 모드팩 출처 모드는 지우면 팩과 어긋날 수 있고, 모드팩을 다시 설치하면 돌아올 수 있습니다.

모드팩 바꾸기

섹션 제목: “모드팩 바꾸기”

모드팩 바꾸기에서 직접 고르기 (버전 · 모드로더) 또는 서버팩 zip 올리기로 새 팩을 고릅니다. 직접 추가한 모드는 그대로 남습니다. 이 모드팩으로 바꾸기 → 다른 모드팩으로 다시 설치할까요? → EULA 동의 후 설치합니다. 되돌리기는 이전 모드팩과 변경 직전 월드 백업 복원을 제안합니다.

CurseForge API 키

섹션 제목: “CurseForge API 키”
용도 API 키
서버팩 zip으로 서버 설치 불필요
CurseForge 검색·모드 추가 필요(선택 설정)
플레이어 프로필 zip·코드(모드팩 배포) 불필요

키는 시스템 설정 → 외부 연동에서 넣습니다.

업데이트 확인

섹션 제목: “업데이트 확인”

패널에 설치된 모드의 CurseForge 최신 버전을 일괄 비교하는 기능은 없습니다. 버전을 올리려면 해당 모드를 다시 추가하거나 jar를 교체합니다.
