설치

내려받아 한 번 실행하면 설치가 끝납니다. 관리자 권한은 필요 없습니다.

  1. 내려받기

    아래 버튼으로 LanternLauncher.exe를 받습니다. 다른 버전은 릴리스 페이지에 있습니다.

    LanternLauncher.exe 받기

  2. 실행하고, SmartScreen이 막으면 허용하기

    Windows가 Windows의 PC 보호 창을 띄울 수 있습니다. 이 런처는 유료 코드 서명 없이 배포되기 때문입니다. 아래의 SmartScreen 안내를 따라 주세요.

  3. 설치 여부에 답하기

    “Lantern Launcher를 설치할까요?”라는 창에서 설치를 누릅니다. 끝나면 작업 표시줄 트레이에 Lantern 아이콘이 나타납니다.

Windows SmartScreen이 막을 때

섹션 제목: “Windows SmartScreen이 막을 때”

SmartScreen은 직접 내려받았고 게시자(코드 서명)가 없는 파일의 실행을 막을 수 있습니다. 최초 설치 때만 나올 수 있는 경고입니다.

  1. 추가 정보 누르기

    Windows의 PC 보호 창에서 추가 정보를 누릅니다.

  2. 실행 누르기

    펼쳐진 창에 실행 버튼이 나타납니다. 누르면 설치가 진행됩니다.

  3. 트레이 아이콘 확인

    설치가 끝나면 트레이에 Lantern 아이콘이 보입니다. 시작 메뉴에도 Lantern 항목이 생겨 Windows 검색으로 찾을 수 있습니다.

앱 안에서 받는 업데이트는 이 경고가 다시 뜨지 않도록 만들어져 있습니다.

내려받은 파일 확인하기

섹션 제목: “내려받은 파일 확인하기”

릴리스에 함께 올라오는 SHA-256 값과 내려받은 파일의 해시를 비교할 수 있습니다. PowerShell에서 실행합니다.

릴리스의 LanternLauncher.exe.sha256 파일 첫 줄(16진수 64자리)과 같아야 합니다.

설치되는 곳

섹션 제목: “설치되는 곳”
  • 프로그램: %LOCALAPPDATA%\Programs\Lantern
  • 설정과 기록: %LOCALAPPDATA%\Lantern\Launcher (로그는 tray.log)
  • 시작 메뉴: Lantern 바로 가기

Windows 시작 시 실행

섹션 제목: “Windows 시작 시 실행”

설치된 런처는 설정의 Windows 시작 시 실행으로 자동 실행을 켜고 끌 수 있습니다. 켜 두면 웹 패널의 서버 들어가기가 바로 런처로 이어집니다. 창을 닫아도 런처는 트레이에서 계속 실행됩니다.

제거

섹션 제목: “제거”

Windows 설정의 앱 목록에서 Lantern을 골라 제거합니다. “Lantern Launcher를 제거할까요?”에 제거를 누르면 프로그램과 시작 메뉴 항목이 삭제됩니다.

CurseForge에 만들어진 모드팩 프로필은 제거 대상이 아닙니다. 필요 없으면 CurseForge 앱에서 직접 지우세요.
