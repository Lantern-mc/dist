서버 만들기

패널에서 마인크래프트 서버를 처음 만들거나, 로더·버전을 바꿔 다시 설치할 때 쓰는 절차입니다. 서버는 패널과 같은 컨테이너에서 돌아가며 게임 포트는 25565를 씁니다.

만드는 방법

섹션 제목: “만드는 방법”

서버 만들기 화면에서 만드는 방법을 고릅니다.

  1. 직접 고르기 — 마인크래프트 버전, 모드로더, 로더 버전을 고릅니다. 모드로더 선택지는 바닐라, Paper, Fabric, Quilt, Forge, NeoForge입니다.
  2. 서버팩 zip 올리기 — CurseForge 모드팩 페이지의 Server Pack(모드가 들어 있는 zip)을 올립니다. 모드 목록만 있는 일반 내보내기 zip은 쓸 수 없습니다. zip 안의 start.bat 등 시작 스크립트는 실행하지 않고, 로더와 버전만 읽습니다.
  3. Modrinth .mrpack — 로더·마인크래프트 버전은 팩에서 가져오고, 모드는 설치 중 Modrinth에서 내려받습니다.

서버팩 zip으로 설치할 수 있는 모드로더는 Forge, NeoForge, Fabric입니다. Quilt·Paper·바닐라는 직접 고르기로 만듭니다.

월드 올리기(선택)

섹션 제목: “월드 올리기(선택)”

**월드 올리기(선택)**에서 level.dat가 있는 월드 폴더를 zip으로 올리거나, 월드 없이 만들기, 모드팩에 포함된 모드팩 안의 월드를 고를 수 있습니다. 모드팩 zip에 월드를 쓰면 별도 월드 zip은 올릴 수 없습니다. 모드 월드는 같은 모드를 서버에 따로 설치해야 열립니다. 자세한 조건은 데이터와 업데이트의 도움말과 같습니다.

Java와 메모리

섹션 제목: “Java와 메모리”

이미지에는 Java 8, 17, 21, 25가 들어 있습니다. 마인크래프트 버전이 요구하는 Java major에 맞춰, 그 이상인 번들 중 가장 작은 런타임을 고릅니다.

Java 메모리 슬라이더로 힙 크기를 정합니다. 쓸 수 있는 메모리는 컨테이너 한도를 넘을 수 없으며, 부족하면 메모리가 부족해 서버를 만들 수 없습니다가 나옵니다. CPU 코어 수, JVM 튜닝(Aikar 플래그 (권장), ZGC · Java 21 이상, 메모리 큰 서버, 없음), 멈추면 다시 켜기는 파일과 서버 설정의 성능에서 나중에 바꿀 수 있습니다.

서버 만들기 절차

섹션 제목: “서버 만들기 절차”
  1. 서버 이름을 입력합니다(기본 우리 서버).
  2. 서버 만들기를 누릅니다. 이미 설치된 서버가 있으면 **다른 버전으로 다시 설치할까요?**에서 계속으로 확인합니다. 설치 전 상태는 백업되고, 실패하면 되돌아갑니다.
  3. Minecraft EULA에 동의해야 합니다 창에서 Mojang EULA에 동의한 뒤 동의하고 서버 만들기를 누릅니다. 동의한 사람과 시각이 기록됩니다.
  4. 설치가 끝나면 콘솔과 부팅 진단에서 서버 켜기로 실행합니다.

로더·버전 변경

섹션 제목: “로더·버전 변경”

로더를 바꾸려면 서버를 다시 설치합니다. 서버 만들기에서 같은 확인·EULA 절차를 거칩니다. 모드만 바꿀 때는 모드와 CurseForge의 모드팩 바꾸기를 쓸 수 있습니다.

관련 문서

섹션 제목: “관련 문서”
  • 처음 패널을 올렸다면 설치하기, Discord 연결을 먼저 확인합니다.
  • 접속 주소는 주소 공개에서 정합니다.
  • 설치·재설치 전후 백업은 백업과 복원을 참고합니다.
