플레이어와 화이트리스트

플레이어 화면에서 화이트리스트·밴·OP·접속 상태를 관리합니다. 멤버는 패널·Discord·런처로 닉네임을 신청할 수 있습니다.

화이트리스트 켜기·끄기

섹션 제목: “화이트리스트 켜기·끄기”
  1. 플레이어 화면에서 화이트리스트 사용을 켭니다.
  2. 끄면 · 끄면 누구나 접속 안내처럼 화이트리스트 없이 접속할 수 있습니다. 변경에는 서버 설정 바꾸기 권한이 필요합니다.

자세한 역할별 승인 없이 등록되는 설정은 역할과-권한의 화이트리스트 바로 등록을 참고하세요.

신청 경로 (패널 · Discord · 런처)

섹션 제목: “신청 경로 (패널 · Discord · 런처)”
경로 설명
패널 화이트리스트 신청 권한이 있는 멤버가 닉네임 등록 흐름으로 신청합니다. 런처가 같은 닉네임을 보고한 경우에만 패널에서 신청할 수 있습니다(바로 등록 역할·화이트리스트 승인 · 추가 · 빼기 권한은 예외).
Discord 길드 안에서 Discord 봇 명령으로 신청합니다. 신청 출처는 Discord로 표시됩니다.
런처 런처가 등록한 기기·닉네임과 일치하면 출처가 런처로 표시됩니다.

Mojang 확인이 잠시 안 되면 신청만 접수되고, 승인할 때 다시 확인합니다.

승인·거절

섹션 제목: “승인·거절”
  1. 플레이어 화면 상단 승인 대기 목록을 엽니다.
  2. 승인 또는 거절을 누릅니다. 거절 시 운영진 메모를 남길 수 있습니다.
  3. 신청자에게 내 신청 결과 알림이 갑니다. 운영진에게는 화이트리스트 신청 알림이 갑니다.

화이트리스트 승인 · 추가 · 빼기 권한이 있거나 역할과-권한에서 바로 등록된 역할이면 신청 즉시 화이트리스트에 올라갑니다.

바로 등록 역할과 자동 제거

섹션 제목: “바로 등록 역할과 자동 제거”

역할과 권한에서 바로 등록에 넣은 패널 역할(관리자·운영자·플레이어·손님 중 선택)을 가진 멤버는 승인 없이 등록됩니다. 그 역할을 잃으면 약 10~20분 뒤 자동 등록 항목만 화이트리스트에서 빠집니다(자동 등록 배지).

관리자가 플레이어 화면에서 직접 추가한 이름, 승인으로 올린 이름, 콘솔에서 넣은 이름은 직접·수동 항목으로 자동 제거 대상이 아닙니다. 길드를 나가면 수동·자동 구분 없이 제거를 시도합니다.

대량 역할 상실 시 화이트리스트 자동 제거를 보류했어요 안내와 그래도 제거가 나올 수 있습니다. Discord-연결·역할 매핑을 확인하세요.

닉네임 바꾸기

섹션 제목: “닉네임 바꾸기”

이미 다른 마크 닉네임이 연결된 멤버가 새 이름으로 신청하면 확인이 필요합니다. 랜딩 내 상태의 닉네임 바꾸기 또는 신청 화면에서 바꿀 이름을 확정합니다.

수동 추가·제거

섹션 제목: “수동 추가·제거”
  1. 마크 닉네임으로 추가로 이름을 넣거나, 사람 행을 열어 화이트리스트에 추가·화이트리스트에서 빼기를 사용합니다.
  2. 정품 계정이 아니거나 다른 멤버가 쓰는 닉네임이면 추가되지 않습니다.

밴

섹션 제목: “밴”
  1. 밴 추가에서 대상(닉네임 또는 IP), 사유, 기간(1일 · 7일 · 영구)을 고릅니다.
  2. 밴을 실행합니다. 밴 · OP 권한이 필요합니다.
  3. 만료된 기간 밴은 스케줄러가 해제합니다. 밴 해제로 즉시 풀 수 있습니다.

OP · 추방

섹션 제목: “OP · 추방”
  • OP 주기·OP 해제: 게임 내 명령 권한이며 패널 역할과 별개입니다(OP는 게임 안 명령어 권한으로, 패널 역할과는 따로입니다.). 서버가 꺼져 있을 때만 OP 레벨(1~4)을 고를 수 있습니다.
  • 추방: 명령어 실행 · 추방 권한으로 접속 중인 플레이어를 쫓냅니다.

접속 세션과 목록

섹션 제목: “접속 세션과 목록”

콘솔 접속·퇴장 로그로 접속 중·마지막 접속·최근 기록이 채워집니다. 랜딩에서는 서버 상태와 접속자 권한이 있을 때 접속자·최근 접속자 목록을 볼 수 있습니다.

서버 켜기 요청

섹션 제목: “서버 켜기 요청”

서버 상태와 접속자(status.view)는 있으나 꺼진 서버 켜기·시작 · 재시작 권한이 없으면, 다른 권한이 있어도 서버가 꺼져 있을 때 랜딩 운영진에게 요청으로 기동을 요청할 수 있습니다. 시작 · 재시작 권한을 가진 운영진에게 서버 켜기 요청 알림이 갑니다. 10분에 멤버당 1회·전체 3회까지입니다.
