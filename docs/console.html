콘솔과 부팅 진단

콘솔 화면에서 서버 전원, 명령, 부하, 접속자를 보고, 모드 서버가 켜지다 멈췄을 때 멈춘 원인 진단을 씁니다.

전원 조작

섹션 제목: “전원 조작”

헤더 버튼은 권한과 상태에 따라 달라집니다.

동작 UI 설명
켜기 서버 켜기 꺼져 있거나 비정상 종료 후. 버튼은 server.start_offline만 보며, API는 server.start_offline 또는 server.restart면 시작을 받습니다
중지 중지 → 정말 중지 두 번 눌러 확인합니다. 이름 입력칸은 없고, 두 번째에 클라이언트가 서버 이름을 confirm으로 보냅니다
재시작 재시작 → 정말 재시작 실행 중·응답 없음 등
강제 종료 강제 종료 켜지는 동안에는 강제 종료만 됩니다. 응답이 없어요일 때도 사용

재시작·중지 시 지금 접속 중인 N명은 연결이 끊깁니다 안내가 나옵니다. 자동 재시작 규칙은 자동화 규칙을 참고합니다.

명령 보내기

섹션 제목: “명령 보내기”

서버가 명령을 받을 수 있는 상태일 때 명령어 입력란에 게임 명령을 넣고 보내기를 누릅니다. ↑로 이전 명령을 불러옵니다. console.command 권한이 필요합니다.

로그는 전체, 채팅, 경고, 명령어 필터와 로그 검색으로 볼 수 있습니다. 실행 중에는 실시간 표시가 켜집니다.

TPS·CPU·메모리

섹션 제목: “TPS·CPU·메모리”

상단 카드에 TPS, CPU 사용률, 메모리(RSS와 힙 사용 · 힙 N GB), 디스크, 백업 개수·다음 자동 백업이 표시됩니다. TPS·CPU·메모리는 최근 구간의 작은 그래프(스파크)와 함께 보입니다. 꺼져 있거나 비정상 종료면 —로 비어 있습니다.

부팅 진단(모드 서버)

섹션 제목: “부팅 진단(모드 서버)”

상태가 비정상 종료(crashed)이고 모드 로더가 있으면, 서버가 꺼졌습니다… 안내와 원인 보기가 나타납니다.

진단은 crashed일 때만 동작합니다. crash-reports의 최신 보고서 또는 logs/latest.log 끝에서 치명적 오류 줄을 뽑아 로그에서 찾은 치명적인 오류로 보여 줍니다. 설치된 모드 중 오류에 이름이 나온 jar, 클라이언트 전용(side: client)으로 표시된 모드를 의심되는 모드로 정렬합니다. 이유는 에러에 이름이 나옴, 클라이언트 전용으로 표시됨 등으로 표시됩니다.

다음 모드를 끄고 서버를 다시 켭니다에서 모드를 고르고 끄고 다시 켜기를 누르면 선택한 모드를 끈 뒤 서버를 켭니다. 클라이언트 전용으로 표시된 모드 — 원인이 아닐 수도 있어요는 참고용입니다. 원인을 못 찾으면 **로그에서 원인이 되는 오류를 찾지 못했어요. 콘솔 로그를 확인하세요.**가 나옵니다. 수동으로는 모드와 CurseForge에서 모두 끄기 등을 씁니다.

접속 중인 플레이어

섹션 제목: “접속 중인 플레이어”

접속 중 카드에 지금 접속한 닉네임 목록과 현재 / 최대 인원이 보입니다. 랜딩 최근 소식에는 N 님이 들어왔어요, N 님이 나갔어요도 쌓입니다. 밴·킥·화이트리스트는 플레이어와 화이트리스트에서 다룹니다.

관련 문서

섹션 제목: “관련 문서”
  • 서버가 아직 없으면 서버 만들기.
  • 설치 중이면 서버를 설치하는 중입니다와 진행 상황 보기로 이동합니다.
  • 오프라인일 때 플레이어 운영진에게 요청은 공지와 알림·랜딩 동작과 연결됩니다.
