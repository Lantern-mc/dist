개인정보 처리방침

초안입니다. 게시 전에 운영자가 검토해야 하며, “확인 필요”로 표시한 항목은 아직 코드에서 확인하지 못한 부분입니다.

Lantern은 무엇을 맡고, 무엇을 맡지 않는가

섹션 제목: “Lantern은 무엇을 맡고, 무엇을 맡지 않는가”

Lantern은 직접 설치해서 쓰는 프로그램입니다. Lantern 프로젝트는 서버를 대신 운영하지 않으며, 플레이어나 운영자의 정보를 Lantern 프로젝트 쪽으로 모으지 않습니다.

  • 웹 패널과 마인크래프트 서버는 각 서버의 운영자가 자기 컴퓨터나 호스팅에 설치해 운영합니다. 패널에 저장되는 정보의 관리 책임은 그 서버의 운영자에게 있습니다. 정보 열람이나 삭제는 해당 서버의 운영진에게 요청하세요.
  • Lantern 런처는 플레이어의 Windows PC에 설치됩니다. 런처가 저장하는 정보는 그 PC 안에 있습니다.
  • 패널과 런처 모두 사용 통계, 광고, 오류 보고를 Lantern 프로젝트나 제3자에게 보내는 기능이 없습니다.

웹 패널이 저장하는 정보

섹션 제목: “웹 패널이 저장하는 정보”

각 서버의 패널 데이터베이스에 저장됩니다.

정보 내용 보관
Discord 계정 Discord 사용자 ID, 이름, 프로필 이미지 주소, 서버에서 가진 역할, 첫·마지막 로그인 시각, 언어 설정 계속 보관. 회원이 직접 탈퇴해 삭제할 수 있습니다 (아래 「삭제」)
마인크래프트 계정 닉네임, UUID (화이트리스트 신청, 런처 연결, 접속 기록에서) 계속 보관 (확인 필요)
화이트리스트 신청 닉네임, UUID, 처리 상태, 처리한 운영진, 메모 계속 보관 (확인 필요)
밴 닉네임 또는 운영자가 입력한 IP 주소, UUID, 사유, 처리한 운영진 기간이 정해진 밴은 기간이 끝나면 만료
접속 기록 마인크래프트 닉네임, UUID, 접속·퇴장 시각 퇴장 후 180일이 지나면 삭제
로그인 세션 세션 토큰의 해시값, 만료 시각 (IP 주소와 브라우저 정보는 저장하지 않음) 만료된 세션은 매일 삭제
런처 연결 기기 이름, 토큰의 해시값, 마지막 사용 시각, 런처가 보고한 닉네임과 UUID 연결 해제 후에도 기록은 남음
감사 로그 누가 언제 어떤 설정이나 작업을 바꿨는지. 처음 설정할 때 설정 코드를 틀리면 요청한 IP 주소도 기록됨 90일 후 삭제
알림 알림 제목과 내용 30일 후 삭제, 회원당 최근 200개까지
브라우저 푸시 푸시 주소와 키(암호화 저장), 브라우저 정보 앞부분 200자 더 이상 전달되지 않는 구독은 삭제
모드팩 내려받기 회원별 마지막으로 받은 버전과 시각 계속 보관
백업 월드와 패널 데이터베이스의 사본 운영자가 정한 보관 개수·기간에 따라 삭제

운영자가 회원을 차단하면 그 회원의 로그인 세션은 바로 삭제되지만, 회원 기록 자체는 남습니다. 차단된 회원이 탈퇴하면 개인 정보는 지워지고, 차단 사실만 되돌릴 수 없는 해시값으로 남습니다 (같은 Discord 계정이 다시 들어와도 차단 상태를 유지하기 위해서입니다).

IP 주소는 런처 연결과 처음 설정 화면의 요청 횟수 제한에 쓰입니다. 이 값은 서버 프로그램이 실행되는 동안 메모리에만 있고, 설정 코드를 틀린 경우에만 감사 로그에 남습니다.

웹 패널이 외부와 주고받는 정보

섹션 제목: “웹 패널이 외부와 주고받는 정보”
대상 이유 오가는 정보
Discord 로그인, 역할 확인, 알림 DM, 공지 게시 로그인 권한은 identify(사용자 ID, 이름, 프로필 이미지)만 요청합니다
Mojang 닉네임으로 UUID 찾기, 프로필 머리 이미지 마인크래프트 닉네임, UUID
CurseForge 모드 검색과 설치 (운영자가 API 키를 넣은 경우) 검색어, 모드 정보
브라우저 푸시 서비스 브라우저 알림 (회원이 켠 경우) 알림 내용
바깥 저장소 백업 복사 (운영자가 따로 켠 경우만) 백업 파일. 암호를 정하면 암호화됩니다
Cloudflare, TCPShield 패널·게임 주소 공개 (운영자가 따로 쓰는 경우만) 접속 요청

웹 패널의 쿠키와 브라우저 저장소

섹션 제목: “웹 패널의 쿠키와 브라우저 저장소”
이름 종류 용도
lantern_session 쿠키 로그인 유지
lantern_oauth_state 쿠키 (10분) Discord 로그인 과정의 위조 방지
lantern_setup_claim 쿠키 처음 설치할 때만 사용
lantern.locale, lantern.locale.owner 로컬 저장소 화면 언어
lantern.welcomed.<회원 ID>, lantern.onb-hidden 로컬 저장소 처음 안내를 봤는지
lantern.branding 로컬 저장소 서버 이름·색 같은 꾸미기 정보 캐시
lantern.next, lantern.chunk-reload 세션 저장소 로그인 뒤 돌아갈 페이지, 화면 다시 불러오기

광고나 사용 통계용 쿠키는 없습니다.

런처가 저장하는 정보

섹션 제목: “런처가 저장하는 정보”

모두 플레이어 PC의 %LOCALAPPDATA%\Lantern\Launcher 안에 저장됩니다.

파일 내용
ms-account.dat 마이크로소프트 계정의 로그인 토큰, 마인크래프트 닉네임과 UUID. Windows 사용자 계정으로 암호화(DPAPI)되어 다른 Windows 사용자나 다른 PC에서는 읽을 수 없습니다
tokens.dat 연결한 서버 패널의 런처 토큰. ms-account.dat과 같은 방식(DPAPI)으로 암호화됩니다
state.json, settings.json 등 연결한 서버 목록, 설정, 실행 상태
logs\launch.log, tray.log 실행 기록

게임 파일은 %LOCALAPPDATA%\Lantern\Game에 있습니다.

런처가 외부와 주고받는 정보

섹션 제목: “런처가 외부와 주고받는 정보”
대상 이유 오가는 정보
Microsoft, Xbox Live, Minecraft 서비스 마이크로소프트 계정 로그인, 자바 에디션 보유 확인, 프로필 로그인 정보 (Microsoft가 처리), 계정 토큰
연결한 서버의 패널 서버 연결, 모드팩 받기, 화이트리스트 확인 기기 이름, 마인크래프트 닉네임과 UUID
GitHub 새 버전 확인과 내려받기 일반적인 웹 요청

런처는 PC에 설치된 CurseForge 앱의 인스턴스 정보를 읽습니다. 사용 통계나 오류 보고를 보내는 기능은 없습니다.

삭제

섹션 제목: “삭제”
  • 패널의 내 정보 (탈퇴): 패널의 「내 계정」 화면에서 직접 탈퇴할 수 있습니다. 확인을 위해 서버 이름을 입력해야 하고, 되돌릴 수 없습니다. 운영진도 회원을 삭제할 수 있고 같은 처리가 적용됩니다.
    • 삭제되는 것: 회원 정보(Discord 계정 연결, 이름, 프로필 이미지 주소, 마인크래프트 닉네임·UUID, 역할과 권한 예외), 로그인 세션, 런처 기기와 연결 코드, 연결 토큰, 알림과 알림 설정, 브라우저 푸시 구독, 모드팩 내려받기 기록, 본인의 화이트리스트 신청, 접속 기록. 마인크래프트 서버의 화이트리스트 항목도 함께 뺍니다 (서버가 켜져 있지 않거나 실패하면 탈퇴 후에도 남을 수 있으며 화면에 알려 줍니다).
    • 익명화되는 것: 감사 로그와 알림 글에 남은 이름은 「탈퇴한 회원」으로 바뀝니다. 누가 어떤 작업을 했는지의 기록 자체는 운영 추적을 위해 남습니다 (감사 로그는 90일 뒤 삭제).
    • 남는 것: 차단된 회원의 차단 사실(위의 해시값). 마인크래프트 서버의 밴 목록과 서버 파일(banned-players.json, ops.json, usercache.json, 월드의 플레이어 데이터와 통계, 서버 로그)은 서버 쪽 기록이라 패널 탈퇴로 지워지지 않습니다. 서버 운영진에게 따로 요청하세요.
    • 백업 안의 사본: 이미 만들어진 백업에는 탈퇴 전 정보가 들어 있고, 그 백업이 보관 기간이 지나 삭제될 때 함께 사라집니다. 탈퇴 즉시 지워지지 않습니다.
    • Discord 쪽 정보와 브라우저 푸시 서비스에 남은 구독 주소는 Lantern이 지울 수 없습니다.
  • 런처 연결 해제: 패널의 런처 기기 목록에서 연결을 해제할 수 있습니다 (회원 본인 또는 운영진).
  • 런처 제거: Windows 설정에서 런처를 제거하면 프로그램과 로그인 토큰(tokens.dat, ms-account.dat)이 지워집니다. 설정과 서버 목록은 %LOCALAPPDATA%\Lantern\Launcher 폴더에 남으며, 필요하면 폴더를 직접 삭제하세요. CurseForge에 만들어진 모드팩 프로필은 CurseForge 앱에서 따로 지워야 합니다.

문의

섹션 제목: “문의”
