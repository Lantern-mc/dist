MCP

MCP는 AI 클라이언트가 Bearer 토큰으로 패널에 붙어, 이 Lantern이 돌리는 한 대의 마인크래프트 서버 파일·콘솔·상태를 다루는 HTTP 엔드포인트입니다. 시스템 설정 MCP에서 토큰을 관리합니다.

토큰 발급·폐기

섹션 제목: “토큰 발급·폐기”
  1. 시스템 설정 웹 접속의 패널 주소가 먼저 정해져 있어야 MCP 접속 주소가 보입니다(패널 주소를 먼저 정하세요).
  2. 이름(예: 내 PC Claude)을 넣고 토큰 만들기를 누릅니다.
  3. 이 화면을 떠나면 다시 볼 수 없습니다. 지금 복사하세요. 안내에 따라 토큰과 접속 주소(<패널 주소>/mcp)를 복사합니다.

동시에 유효한 토큰은 하나뿐입니다(이미 쓰는 토큰이 있습니다. 먼저 폐기하세요.). 만료는 발급 후 30일입니다. 폐기하면 해당 AI 연결이 즉시 끊깁니다.

관리자 역할만 발급·폐기할 수 있습니다(관리자 권한과 같으니 공유하지 마세요.).

클라이언트 연결

섹션 제목: “클라이언트 연결”

MCP 클라이언트에 Streamable HTTP URL <패널 주소>/mcp와 Authorization: Bearer <토큰>을 넣습니다. Host·Origin은 설정된 패널 주소와 같아야 하며, 쿠키·CSRF는 사용하지 않습니다. 토큰이 폐기·만료되었거나 발급자가 관리자가 아니거나 길드를 떠나면 401입니다.

제공 도구와 제한

섹션 제목: “제공 도구와 제한”
도구 용도 제한 요약
server_status 상태·접속자 읽기 전용
server_metrics CPU·메모리·TPS 등 읽기 전용
console_tail 최근 콘솔(최대 200줄) 마스킹
console_command 게임 명령 1줄(256자) stop·restart·op·whitelist·ban 등 거부; 꺼짐·크래시·중지 중 not_running; 백업 중 save-on/save-off/save-all/stop/execute/restart만 거부
list_files / read_file 서버 디렉터리 탐색·읽기(1MiB) 서버 폴더 밖 불가
write_file / make_dir / rename_path / delete_path 파일·폴더 변경 실행 중 월드·server.properties·화이트리스트/ops/밴 목록 쓰기 거부; run.sh·start*·libraries/**/*args.txt 항상 거부

콘솔 도구는 호스트 셸이 아니라 게임 콘솔 한 줄입니다. 변경 작업은 source=mcp로 감사 로그에 남습니다.

보안

섹션 제목: “보안”
  • 토큰 유출 시 파일 수정·삭제와 허용된 콘솔 명령까지 가능하므로 공유·저장소 커밋에 넣지 마세요.
  • 토큰은 Authorization 헤더만 사용합니다.
  • 패널 데이터베이스·백업·시크릿 파일 경로는 MCP 범위 밖입니다.
