받기

서버 프로그램 받기

Lantern은 Discord 커뮤니티 하나, 웹 패널 하나, 마인크래프트 서버 하나를 위한 자체 호스팅 패널입니다. 여러 서버를 모아 관리하는 용도가 아닙니다.

Docker Compose로 서버와 패널을 함께 실행합니다.

주소 공개 전 컨테이너 이미지

docker compose up -d

설치가 끝나면 로그에 Lantern 설정 코드: XXX-XXX가 출력됩니다. 첫 접속 때 이 코드로 패널을 엽니다.

콘솔

켜기, 끄기, 재시작, 강제 종료, 명령 보내기. TPS, CPU, 메모리를 함께 봅니다. 모드 서버가 켜지다 멈추면 부팅 진단이 원인을 짚어 줍니다.

백업

백업 만들기, 복원, 고정, 내려받기. 해시가 저장된 백업은 복원 전에 SHA-256을 확인합니다. 일정·시스템 백업·바깥 저장소 복사(선택)도 여기서 다룹니다.

모드

서버 모드 올리기·켜고 끄기, CurseForge 연동, 플레이어 모드팩 zip과 공유 코드. 런처가 같은 팩으로 맞춰 줍니다.

플레이어

화이트리스트 신청 승인·거절, 밴·OP·킥, 권한과 멤버 예외, 공지와 알림(Discord DM 포함), 감사 로그 CSV 내려받기.

파일 · 설정

파일 올리기·폴더·삭제·내려받기, MOTD·게임 규칙·월드 초기화. 서버 설정과 위험 구역(전체 초기화)도 설정 메뉴에 있습니다.

자동화 규칙

설정 › 자동화에서 규칙(20개까지)을 만듭니다: 서버 시작·종료·정지·매일·한가할 때 게임 명령, 셸 명령, 대기. 재시작은 매일·한가할 때 규칙에서만 쓸 수 있습니다.
