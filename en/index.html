Lantern

A Minecraft server for one Discord server

Each server gets its own web panel, and you manage everything there, from installation to backups and mods. You log in with your Discord account, and players connect with the Windows launcher.

01 · Easy

Setup and console, both on the web

  1. Pick a loader (Vanilla, Fabric, Forge, NeoForge or Paper) and a version, and the server is created.
  2. Installation progress is shown.
  3. Once the server is running, you can see the console log, TPS, CPU and memory.
  4. Set up tasks such as a daily restart as automation rules.

03 · Permissions

Permissions come from Discord roles

  1. Set Admin, Operator, Player and Guest permissions for each Discord role.
  2. Whitelist requests show up in the panel as cards.
  3. Click Approve and the player is added to the whitelist.
  4. The player gets an approval notice by Discord DM and joins straight from the launcher.

04 · Mods

Players don't have to match mods themselves

  1. Upload mods to the server in the panel.
  2. An update notice appears in the launcher.
  3. The player clicks Join server in the server's web panel.
  4. The launcher downloads the changed mods and starts the game.

05 · Backups

Roll back when it breaks

  1. Backs up automatically at the times you set.
  2. Automatic and manual backups pile up in the list.
  3. Pick a backup to restore, and the current world is backed up first, then restored.
  4. Before restoring, SHA-256 is used to check the file is intact.
