Changelog

Downloads for every version are on the Download page.

0.2.6

current

Fixes

  • When the server is off or cannot be joined, Quick join is disabled and the status is shown above the button. Launch game still works.
  • When the signed-in account is not whitelisted or is waiting for approval, both Quick join and Launch game are disabled. An unknown answer, a failed check, or being signed out does not block the buttons.
  • Check now applies an update whose mod list did not change, in place.
  • A pack whose mods changed is installed with the launcher's Update button, without opening the web panel.
  • Stop during an update cancels the apply. The next launch finishes the remaining files first.
  • An update that stopped halfway replaces the mixed files. If the server cannot be reached, the launcher asks whether to start anyway.
  • Settings files the pack did not change are kept.
  • After the game starts, the launcher offers to remove the previous profile, and deleting the server removes those older profiles too.
  • An install on this PC is no longer stuck when there is no delete permission. The previous profile is kept and you are told.

0.2.5

Fixes

  • Clicking the tray icon could freeze the launcher so nothing worked
  • Installing a launcher update now says the download started, and says the new version is in place after the restart
  • Pressing update again during the download only says it is downloading
  • A launcher update no longer stops on a check-file format error
  • Reinstalling the launcher before a self-update had finished made every start report "could not roll back to the previous version"
  • A pack update with the same mod list no longer asks you to update on the web panel: pressing Launch game applies it
  • The update notice's web button opened a page without a modpack button: it now opens the panel home with "Join server"

0.2.1

Updates

  • Play first checks whether the server pack changed and, when the mod list is the same, applies it before starting
  • An update that changes the mod list is announced before starting
  • Only changed files are downloaded, so updates are faster
  • Resource packs chosen by the server are turned on once

Fixed

  • Old mods and resource packs with a new name stayed behind after a pack update
  • Settings files the pack did not change (options.txt and others) were overwritten on every update
  • A failed update no longer stops you from playing the previous version

0.2.0

New

  • A server notices card on the home screen
  • Server online/offline status on the home screen and in the list on the left
  • A check, before the game starts, that your nickname is on the whitelist
  • Servers you allowed but whose install is not finished now appear in the list
  • The server's title image is drawn on the home screen
  • One name, Lantern Launcher, and the join button is now Join server

Install and updates

  • The install waits by watching progress, and can be retried after a failure
  • Fixed an unfinished install being shown as up to date
  • Starting the game from the web panel link now joins the server straight away
  • A changed or cleared server address now reaches this PC's multiplayer list as well
  • When the server refuses you, the reason is stated instead of a generic “reconnect”
  • Instances are read even while CurseForge has their files open, and a mod you add yourself in CurseForge no longer makes the modpack look incomplete

Screen and stability

  • Fixed the system title bar showing behind a popup
  • Buttons on a status card now wrap to the next row instead of running past the card edge
  • Fixed an error when a window message arrived while the display scale was being resolved
