Get the server software

Lantern is a self-hosted panel for one Discord community, one web panel and one Minecraft server. It is not meant for managing several servers in one place.

Docker Compose runs the server and panel together.

Not published yetContainer image

docker compose up -d

When installation finishes, the log prints Lantern setup code: XXX-XXX. Use this code to open the panel the first time you connect.

Console

Start, stop, restart, force kill and send commands. TPS, CPU and memory are shown alongside. If a modded server stops while starting up, the boot diagnosis points to the cause.

Backups

Create, restore, pin and download backups. For backups with a stored hash, SHA-256 is checked before restoring. Schedules, system backups and optional copies to outside storage are handled here too.

Mods

Upload server mods and turn them on or off, CurseForge integration, the player modpack zip and share code. The launcher syncs players to the same pack.

Players

Approve or decline whitelist requests, ban, OP and kick, permissions and member exceptions, announcements and notifications (including Discord DM), and audit log CSV download.

Files · Settings

Upload, create folders, delete and download files; MOTD, game rules and world reset. Server settings and the danger zone (full reset) are in the Settings menu too.

Automation rules

Under Settings › Automation you create rules (up to 20): game commands, shell commands and waits, on server start, exit, stop, daily, or when idle. Restart can only be used in daily and when-idle rules.
