Troubleshooting

The cases people run into most. Click a question to open it.

The install failed

Section titled “The install failed”

The home screen shows a There is a problem with this server card with the reason underneath. Use its buttons like this.

  • Try again: runs the same install again. Best first move after a short network drop.
  • Connect an existing CurseForge instance…: if CurseForge already has a profile of this modpack, link it to the Launcher.
  • Open web panel: go to the server’s web panel and press Join server again.

If the game could not start, an Open log folder button is shown as well.

It says the server is offline

Section titled “It says the server is offline”

Server is offline or unreachable means the server may not be running yet or there is a temporary network problem. Connecting may fail. Try Check now in the More menu after a moment. If it stays off, tell the server staff.

Unreachable and Panel offline are states the server side has to look at.

It says my account is not whitelisted

Section titled “It says my account is not whitelisted”

Your nickname is not on the server’s whitelist. Ask the server staff to add it. If it says Whitelist request pending, your request exists; wait for approval. You can still start the game with Play anyway in the meantime, but the server may refuse you.

SmartScreen blocks it

Section titled “SmartScreen blocks it”

If the Windows protected your PC window appears at the first install, click More info and then Run anyway. The steps are on the Install page.

CurseForge app not found

Section titled “CurseForge app not found”

When you see CurseForge app required, press Get CurseForge to install the CurseForge app, and press Check again once it is done. If it is installed and still not found, the CurseForge row in Settings has a Change button to point the Launcher to it.

The game closes right after starting

Section titled “The game closes right after starting”

You get “The game closed right after starting”. It may be a mod conflict or low memory. Raise Max memory in Settings, or Try again on the install.

I cannot sign in

Section titled “I cannot sign in”

The Microsoft account has to own Minecraft: Java Edition. For a child account, a guardian must allow online play in Microsoft Family settings. Closing the sign-in window cancels it, so finish in the browser and wait for the window to close by itself.

It says the connection code expired

Section titled “It says the connection code expired”

A connection code works once and expires after a while. Press Join server on the web panel again to get a new one.

Where are the logs?

Section titled “Where are the logs?”

The Launcher writes to %LOCALAPPDATA%\Lantern\Launcher\tray.log. You do not have to remember the path: Open log folder in Settings opens it.

How to ask for help

Section titled “How to ask for help”

Ask the person who runs your server, or that server’s help channel. These details get it solved faster.

  • The Launcher version (the current version shown under About in Settings)
  • What you pressed and which message appeared (a screenshot)
  • The last part of tray.log

The log can contain folder names from your PC, so remove personal details such as your user name before posting it anywhere public.
