Privacy policy

Draft. Operators should review before publishing. Items marked “needs verification” are not yet confirmed in code.

What Lantern handles and what it does not

Section titled “What Lantern handles and what it does not”

Lantern is software you install yourself. The Lantern project does not run servers for you and does not collect player or operator information on Lantern project systems.

  • The web panel and Minecraft server are installed and operated by each server’s operator on their own computer or hosting. The operator is responsible for information stored in the panel. For access or deletion, contact that server’s staff.
  • The Lantern launcher is installed on the player’s Windows PC. What the launcher stores stays on that PC.
  • Neither the panel nor the launcher sends usage analytics, ads or crash reports to the Lantern project or third parties.

Information the web panel stores

Section titled “Information the web panel stores”

Stored in each server’s panel database.

Information Contents Retention
Discord account Discord user ID, name, profile image URL, roles on the server, first and last login times, language preference Kept until the member deletes their account (see Deletion below)
Minecraft account Nickname, UUID (from whitelist requests, launcher connection, join history) Kept (needs verification)
Whitelist request Nickname, UUID, status, staff who handled it, notes Kept (needs verification)
Ban Nickname or IP entered by staff, UUID, reason, staff who applied it Timed bans expire when the period ends
Join history Minecraft nickname, UUID, join and leave times Deleted 180 days after leave
Login session Hash of session token, expiry time (IP and browser info are not stored) Expired sessions deleted daily
Launcher connection Device name, hash of token, last used time, nickname and UUID reported by the launcher Record remains after disconnect
Audit log Who changed which setting or action when. Wrong setup code on first setup may also log the request IP Deleted after 90 days
Notifications Notification title and body Deleted after 30 days, up to 200 recent per member
Browser push Push endpoint and keys (encrypted), first 200 characters of browser info Subscriptions that can no longer be delivered are removed
Modpack download Last version and time each member downloaded Kept
Backups Copies of world and panel database Removed per operator retention count and age

When an operator blocks a member, that member’s login sessions are removed immediately, but the member record remains. If a blocked member deletes their account, personal data is erased and only the block fact remains as a non-reversible hash (so the same Discord account cannot bypass the block).

IP addresses are used for launcher connection and rate limiting on the first-time setup screen. They live in memory only while the server process runs, except when a wrong setup code is logged in the audit log.

Cookies and browser storage (web panel)

Section titled “Cookies and browser storage (web panel)”
Name Type Purpose
lantern_session Cookie Stay signed in
lantern_oauth_state Cookie (10 minutes) CSRF protection during Discord login
lantern_setup_claim Cookie First-time install only
lantern.locale, lantern.locale.owner Local storage UI language
lantern.welcomed.<member ID>, lantern.onb-hidden Local storage Whether onboarding was seen

There are no cookies for ads or usage analytics.

Information the launcher stores

Section titled “Information the launcher stores”

All under %LOCALAPPDATA%\Lantern\Launcher on the player’s PC.

File Contents
ms-account.dat Microsoft sign-in token, Minecraft nickname and UUID. Encrypted with DPAPI for the Windows user account — other Windows users or PCs cannot read it
tokens.dat Launcher tokens for connected server panels. Encrypted the same way as ms-account.dat
state.json, settings.json, etc. Connected servers, settings, run state
logs\launch.log, tray.log Run logs

Game files are under %LOCALAPPDATA%\Lantern\Game.

Information the launcher exchanges externally

Section titled “Information the launcher exchanges externally”
Party Why What is sent
Microsoft, Xbox Live, Minecraft services Microsoft sign-in, Java Edition ownership check, profile Sign-in handled by Microsoft, account token
Connected server panels Connect, download modpack, whitelist check Device name, Minecraft nickname and UUID
GitHub Check for and download new launcher versions Ordinary web requests

The launcher reads installed CurseForge app instance information locally. It does not send usage analytics or crash reports.

Deletion

Section titled “Deletion”
  • My account (leave the panel): On the My account page you can delete your own membership. You must type the server name to confirm; it cannot be undone. Staff can delete a member with the same effect.
    • Removed: Member profile (Discord link, name, profile image URL, Minecraft nickname and UUID, roles and permission exceptions), login sessions, launcher devices and connection codes, connection tokens, notifications and notification settings, browser push subscriptions, modpack download history, your whitelist requests, join history. Your Minecraft whitelist entry is removed too (if the server is off or removal fails, it may remain and the UI will say so).
    • Anonymized: Names in the audit log and notification posts become Former member. The record of what was done stays for operator oversight (audit log deleted after 90 days).
    • Not removed by panel deletion: Block fact for blocked members (hash above). Minecraft server ban list and server files (banned-players.json, ops.json, usercache.json, world player data and stats, server logs) are server-side — ask server staff separately.
    • Copies in backups: Existing backups may still contain pre-deletion data until those backups age out under retention. Deletion does not erase backup files immediately.
    • Lantern cannot remove data on Discord or subscriptions left at the browser push service.
  • Disconnect launcher: On the panel launcher device list, disconnect (member or staff).
  • Uninstall launcher: Removing the launcher in Windows Settings deletes the program and sign-in tokens (tokens.dat, ms-account.dat). Settings and server list may remain under %LOCALAPPDATA%\Lantern\Launcher — delete the folder if you want. Modpack profiles in CurseForge must be removed in the CurseForge app.

Contact

For the Lantern software itself, use Issues on the GitHub repository. For data held by a specific server, contact that server’s operators.
