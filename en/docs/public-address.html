Public addresses

Players and operators use two kinds of address. Configure the panel (HTTPS, Discord OAuth) and the game (TCP 25565, optionally TCPShield) separately.

Panel web address

Section titled “Panel web address”

Under Settings › Address › Web access, set Panel address (public_url). Discord OAuth redirect is …/api/auth/callback based on this value.

  • When exposing to the internet, do not leave 8080 open as-is. Put HTTPS reverse proxy or Cloudflare Tunnel in front (docker/IMAGE_README.md).
  • When changing the address, align Discord Developer Portal Redirects first, then save after checking I’ve read the above.

For local testing only, http://localhost:8080 may work, but Discord login and cookies are safest with a public HTTPS URL.

Game join address

Section titled “Game join address”

On Settings › Address › the Access card (Game address), put the host (and :port if needed) that players enter in multiplayer in the Address field. If empty, players do not see an address on their screen (Leave it empty and players will not see an address.).

The default Minecraft port is 25565. compose.yaml publishes host 25565:25565. Port can be changed in server settings; with TCPShield, align TCPSHIELD_GAME_PORT too.

You can use This panel’s address: … with Use this as a draft game address. TCPShield and voice chat usually need separate DNS names (TCPShield section below).

Cloudflare Tunnel (panel, optional)

Section titled “Cloudflare Tunnel (panel, optional)”

Only panel HTTP (container 8080) goes through the tunnel. The game port does not use this tunnel.

  1. In Cloudflare Zero Trust, create a tunnel and point a public hostname service to http://localhost:8080.
  2. cp cloudflared.env.example cloudflared.env and set CLOUDFLARED_TUNNEL_TOKEN= to your token.
  3. docker compose -f compose.yaml -f compose.cloudflared.yaml up -d

compose.cloudflared.yaml clears host port publishing (ports: !reset []). With TCPShield, stack -f compose.yaml -f compose.cloudflared.yaml -f compose.tcpshield.yaml. The TCPShield file publishes the UDP tunnel port again.

100MB upload limit

Section titled “100MB upload limit”

Cloudflare (Free and Pro) rejects request bodies over 100MB before they reach the panel. Separate from the panel upload limit.

  • Files over 90MiB are split into 50MiB chunks by the panel (help.json Uploading large files). Chunked upload avoids the 100MB limit even behind a tunnel.
  • Restore from a backup upload in the setup wizard uses only the setup code and does not use chunked upload. For large system backups, consider CLI restore (docs/ops/restore-runbook.md).

TCPShield (game, optional)

Section titled “TCPShield (game, optional)”

Put game TCP behind TCPShield with a Sentry Tunnel. Separate from web panel paths.

  1. Copy the Sentry Tunnel Setup Script from the TCPShield panel into tcpshield.env (cp tcpshield.env.example tcpshield.env).
  2. Forward UDP TCPSHIELD_PORT on the router or firewall to this host.
  3. docker compose -f compose.yaml -f compose.tcpshield.yaml up -d
  4. Point the TCPShield backend at the tunnel public IP (TCPSHIELD_IP) and game port.

Inside the tunnel, iptables blocks 8080 (panel) and 25575 (RCON) from outside. Game TCP is accepted only from the TCPShield proxy range (TCPSHIELD_ALLOW, default 198.178.119.0/24 104.234.6.0/25).

On Docker Desktop / WSL2, connections can stall in SYN-RECV unless vxlan tx checksum offload is off. docker/entrypoint.sh runs ethtool -K vxlan_<id> tx off.

Simple Voice Chat UDP needs an A record to the tunnel IP (not CNAME for TCP only) and LANTERN_VOICE_HOST, LANTERN_VOICE_BIND (docs/ops/tcpshield.md).

RCON and internal ports

Section titled “RCON and internal ports”

RCON 25575 is internal only and is not published in compose.yaml. The panel sets a new rcon.password each time the server starts.

Common symptoms

Section titled “Common symptoms”
Symptom Check
Discord login fails Panel address, redirect, HTTPS
Server list ping works but join fails TCPShield tunnel, checksum offload, backend IP
Direct join to <tunnel IP>:25565 works TCPSHIELD_ALLOW, tunnel firewall
Large zip upload aborts Cloudflare 100MB; chunked upload or bypass (docs/wiki/networking-troubleshooting.md §4)
Voice chat only fails voice_host, UDP A record, bind_address

More cases: docs/wiki/networking-troubleshooting.md. Related: Install the panel, Data location and updates, Troubleshooting.
