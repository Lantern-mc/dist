Changelog

Downloads for every version are on the Download page.

0.2.11

Section titled “0.2.11”

Current version

Fixes

Section titled “Fixes”
  • When the server’s profile code and modpack files list different mods, the launcher says so right away instead of waiting for the install, and the notice lists the mods that differ. Please pass it on to the staff.
  • Deleting two servers at almost the same time no longer fails.
  • Check now also says why an update waits when the Java program could not be inspected right before the update.

0.2.10

Section titled “0.2.10”

Includes the changes of 0.2.9.

Fixes

Section titled “Fixes”
  • A server link from the web panel that arrives while the game is starting no longer updates that game’s files; the update waits.
  • When an update is put off because a running Java program could not be inspected (including Check now), the launcher says so. If it is not the game, close it and try again.
  • Deleting a server is no longer blocked by leftovers of an earlier delete of the same server, and the empty trash folder is cleaned up.
  • A pack update that swaps mods but keeps the same number of mods now shows the update card in the background check too.
  • A mod file that declares several mod IDs is matched on all of them, so the same mod is no longer loaded twice.
  • Abnormally long link requests are dropped without being read.

0.2.8

Section titled “0.2.8”

Includes the changes of 0.2.7.

Window and notices

Section titled “Window and notices”
  • Pressing Join server in the web panel brings the launcher forward with that server selected, so you can see the progress.
  • Settings let you choose what the launcher window does when the game starts: minimize (default), hide to tray, or keep open.
  • Settings let you choose whether the close button (X) hides the launcher to the tray (default) or quits it.
  • The “Ready” window no longer appears when the launcher starts the game itself.
  • Questions that come up after the game started (such as cleaning up the previous profile) no longer jump over the game; the taskbar button flashes instead.
  • The Sign in with Microsoft and Get CurseForge buttons on the first-run screens are no longer hidden.

When CurseForge is missing

Section titled “When CurseForge is missing”
  • Installing a new server without CurseForge shows a “CurseForge is needed” window with a Get CurseForge button before the link is used.
  • An install that fails because CurseForge is missing says so, with the download button, instead of an unreadable error.
  • Playing a server that is already installed still works without CurseForge.

Installs and updates

Section titled “Installs and updates”
  • The server’s picture and title no longer turn into the default art during a modpack update.
  • However a modpack spells its paths, the player’s worlds (saves) are never overwritten or deleted.
  • After you move the CurseForge folder, an old profile no longer blocks an install. It is kept and you are told.
  • Installing or updating one server no longer blocks work on other servers.
  • When a mod is updated under a different file name, the same mod (mod ID) is no longer loaded twice. An old file with the same ID as a pack mod is renamed to .lantern-old, which the game does not read. Nothing is deleted.
  • If the launcher’s server record file is damaged by a sudden shutdown, it is restored from the previous copy.

Adding servers and accounts

Section titled “Adding servers and accounts”
  • Adding a server with an empty folder, or an instance another server already uses, is refused right away. If the folder is not that server’s modpack, the add is undone and you are asked to try again with a new link.
  • After you switch Minecraft accounts, the previous account’s whitelist answer no longer leaves Quick join and Launch game disabled.
  • A whitelist check that fails briefly keeps the last answer, so the buttons no longer flip on and off.
  • When the server is off, “Offline” is shown once.
  • Check for updates in Settings checks right away, and says it could not check instead of “no new version” when it could not.
  • CurseForge import codes no longer appear in failure notices or logs when an install or launch fails.

0.2.6

Section titled “0.2.6”

Fixes

Section titled “Fixes”
  • When the server is off or cannot be joined, Quick join is disabled and the status is shown above the button. Launch game still works.
  • When the signed-in account is not whitelisted or is waiting for approval, both Quick join and Launch game are disabled. An unknown answer, a failed check, or being signed out does not block the buttons.
  • Check now also applies an update whose mod list did not change, in place.
  • A pack whose mods changed is announced before starting and installed with the launcher’s Update button, without opening the web panel.
  • Stop during an update cancels the apply. The next launch finishes the remaining files first.
  • An update that stopped halfway replaces the mixed files. If the server cannot be reached, the launcher asks whether to start anyway.
  • Settings files the pack did not change (options.txt and others) are kept.
  • After the game starts, the launcher offers to remove the previous profile, and deleting the server removes those older profiles too.
  • An install on this PC is no longer stuck when there is no delete permission. The previous profile is kept and you are told.

0.2.5

Section titled “0.2.5”

Fixes

Section titled “Fixes”
  • Clicking the tray icon could freeze the launcher so nothing worked. Fixed.
  • Installing a launcher update says the download started, and says the new version is in place after the restart.
  • Pressing update again during the download only says it is downloading.
  • A launcher update no longer stops on a check-file format error.
  • Reinstalling the launcher before a self-update had finished no longer makes every start report “could not roll back to the previous version”.
  • Fixed an issue where pack updates with an unchanged mod list still told you to update on the web panel: pressing Launch game now applies it automatically.
  • Fixed the update notice’s web button opening a page without a modpack download button: it now directs to “Join server” on the panel home screen.

0.2.1

Section titled “0.2.1”

Updates

Section titled “Updates”
  • Pressing play first checks whether the server pack changed and, when the mod list is the same, applies it automatically before starting.
  • A pack whose mods changed is announced before starting.
  • Only changed files are downloaded, so updates are faster.
  • Resource packs chosen by the server are turned on once automatically.

Fixes

Section titled “Fixes”
  • Old mods and resource packs with a new name no longer stay behind after a pack update.
  • Settings files the pack did not change (options.txt and others) are no longer overwritten on each update.
  • An update that fails halfway still lets you keep playing on the previous version.

0.2.0

Section titled “0.2.0”

New

Section titled “New”
  • A server notices card on the home screen
  • Server online/offline status on the home screen and in the list on the left
  • A check, before the game starts, that your nickname is on the whitelist
  • Servers you allowed but whose install is not finished now appear in the list
  • The server’s title image is drawn on the home screen
  • One name, Lantern Launcher, and the join button is now Join server

Installs and updates

Section titled “Installs and updates”
  • The install waits by watching progress, and can be retried after a failure
  • Fixed an unfinished install being shown as up to date
  • Starting the game from the web panel link now joins the server straight away
  • A changed or cleared server address now reaches this PC’s multiplayer list as well
  • When the server refuses you, the reason is stated instead of a generic “reconnect”
  • Instances are read even while CurseForge has their files open, and a mod you add yourself in CurseForge no longer makes the modpack look incomplete

Screen and stability

Section titled “Screen and stability”
  • Fixed the system title bar showing behind a popup
  • Buttons on a status card now wrap to the next row instead of running past the card edge
  • Fixed an error when a window message arrived while the display scale was being resolved
