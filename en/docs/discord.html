Connect Discord

Lantern signs you in with Discord OAuth and uses a bot for guild members, roles, notifications, and whitelist request cards. It is built for one community Discord server.

Create a Discord application

Section titled “Create a Discord application”
  1. In the Discord Developer Portal, create a New Application.
  2. In Bot, turn the bot on.
  3. Under Bot › Privileged Gateway Intents, turn on Server Members Intent. Role lists and member sync need it (setup copy: Can read the member list).
  4. Under OAuth2 › Redirects, add https://<panel-domain>/api/auth/callback for your panel URL. It must match Add this address under OAuth2 › Redirects.

The login scope is identify only (backend/lantern/discord/rest.py). Only Discord name and guild membership and roles are used; messages and other servers are not read (Continue with Discord on the login screen).

Values for the panel

Section titled “Values for the panel”

First time at /setup, later under Settings › Discord or Settings › Panel for the same fields.

Field Purpose
Setup code Code from container logs for first setup or recovery. The field locks after Discord connection is saved
Application ID OAuth client ID
Client secret OAuth secret
Bot token Gateway bot login
Web address of this panel Public HTTPS URL used to compute OAuth redirect

Check connection / Check again verify:

  • App details are correct — ID and bot token belong to the same app
  • Bot logged in
  • Bot is in the server — invite the guild with Invite the bot
  • Can read the member list — Server Members Intent

If the bot is in one guild, it connects automatically; if several, pick Discord server to connect then Connect this server. Shown as Connected servers: ….

If Web address of this panel and the browser URL differ, you see a warning to Open this panel at … to set it up.

Sign-in and admin

Section titled “Sign-in and admin”

Log in to Discord with this browser finishes OAuth; that session’s Discord account becomes the first admin. Accounts not in the guild are rejected with Only members of our Discord can get in.

When you change Panel address, register the new …/api/auth/callback in Discord Developer Portal Redirects first (If you change the address, first add … to Redirects in the Discord Developer Portal).

What the bot does

Section titled “What the bot does”

Discord DM

Section titled “Discord DM”

Per notification type you can turn on Discord DM in notification settings. Discord DM becomes available once the bot is connected. applies until the bot is online. Quiet hours apply to browser and DM only.

Announcements and channels

Section titled “Announcements and channels”

Under Settings › Discord, set text channels:

  • Channel IDs for status, requests, announcements, and chat
  • Post announcement posts to the Announcement channel
  • Chat link connects Minecraft chat and a Discord channel. Turn on Message Content Intent in the Discord Developer Portal

The requests channel gets whitelist request cards and threads. Staff can approve or reject from the card.

Slash commands

Section titled “Slash commands”

Guild slash commands (English Discord client names):

Command Description
status Server status
start Start a stopped server (with permission)
backup Create a backup (with permission)
world-reset Delete the world and create a new one (permission and confirmation)
request Whitelist request with a nickname argument

Replies only you see follow Discord client language, then panel locale, then Bot language (Korean / English).

Roles

Section titled “Roles”

Link Discord roles to operator and player cards in Roles and permissions. If the bot cannot fetch roles, use Discord role IDs (comma-separated) instead.

Troubleshooting

Section titled “Troubleshooting”
Symptom Check
Bot login failed Re-copy Bot token, reissue token, then Check again
Bot is not in the server Invite the bot, bot has guild access
Can’t read the member list Server Members Intent, re-invite bot
Couldn’t connect to Discord Redirect URL, Panel address, HTTPS
Only members of our Discord… User joined the Discord server
Everyone Guest right after login No Discord role links yet. Roles and permissions or assign roles on Players
Chat link silent Message Content Intent, Chat channel selected

When the bot disconnects, use Reconnect under Settings › Discord or on the system screen.

If Discord connection is lost: docker compose exec lantern lantern recover → new setup code, enter keys only, set admin again.
