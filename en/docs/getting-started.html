Getting started

On first start the launcher shows a welcome screen and checks three things before you begin. Follow them in this order. You can see the guide again later with Show welcome guide again in Settings.

  1. Check the CurseForge app

    CurseForge installs modpacks; the launcher starts the game. When the launcher finds the app it says CurseForge found.

    • If it does not, you see CurseForge app not found. Press Get CurseForge to install the CurseForge app, then press Check again.
    • If you do not want to install it right now, Install later lets you continue.

  2. Sign in with Microsoft (optional)

    Press Sign in with Microsoft and Microsoft handles the sign-in in your browser. Sign in once and every Lantern server uses the same account. You need an account that owns Minecraft: Java Edition.

    To skip it for now press Sign in later; you can do it in Settings at any time. Without signing in the launcher cannot start the game itself, so you start it through CurseForge.

  3. Connect a server

    Servers are added from their own web panel. Once connected they stay in your list. The person who runs the server tells you which web panel to use.

    1. Sign in to the server’s web panel.
    2. Press Join server.
    3. Allow the connection in the window that opens in the launcher.

    The web panel makes a connection code that works once. If a message says the code expired or was already used, press Join server on the web panel again.

  4. Modpack install

    Once you allow the connection the launcher starts installing the modpack. An Installing modpack card appears on the home screen with a progress bar and a count. Wait for it to finish; press Stop to halt it.

    If the profile file (a zip) from the server has to be imported into CurseForge by hand, you get a The profile has to be imported by hand card. Import it in CurseForge, then press Pick folder and point the launcher to that folder.

  5. Play

    When the install is done the home screen shows a Join server button. Press it and the game starts and connects to the server as soon as it is running. The usage page explains the screen in detail.
