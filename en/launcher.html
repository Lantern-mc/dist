Join a server with the Lantern launcher

Click Join server in the web panel of the server you want to join, and the launcher installs the modpack and connects to the server.

Before you start

Server web panel address

Every Lantern server has its own website (the web panel). Get the address from the server admins.

Windows

This is a Windows program.

CurseForge app

Modpacks are installed with the CurseForge app. The launcher starts the game.

Microsoft account

Log in with an account that owns Minecraft Java Edition.

Whitelist check

On servers that use a whitelist, the server checks whether the nickname and UUID of the signed-in Microsoft account are on the list. The check cannot be done while you are signed out, but you can continue without it with Launch with CurseForge.

Get the launcher

Installs without administrator rights.

Get the launcher
  • SmartScreen — Because the file is not signed, Windows may show a Windows protected your PC window. Click More info → Run anyway to continue the installation.
  • Verify the file — With PowerShell Get-FileHash, you can compare the SHA-256 of the downloaded executable with the first line of the hash file posted with the release.
  • Uninstall — Remove Lantern in Windows Settings › Apps. Your CurseForge profiles stay as they are.

More on installing, SmartScreen and uninstalling (Korean)

On first run

First launch

  1. Check that the CurseForge app is installed.
  2. Log in with your Microsoft account.
  3. Open the server web panel address you got from the admins, log in with Discord, click Join server, then allow the connection in the launcher window.
  4. The launcher installs and syncs the modpack.
  5. Click Launch game to join the server.

Whitelist status
