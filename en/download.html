After you download

  1. Open the file

    Open LanternLauncher.exe. If Windows shows "Windows protected your PC", choose More info, then Run anyway.

  2. Get your accounts ready

    Make sure the CurseForge app is installed, then sign in with the Microsoft account that owns Minecraft.

  3. Join the server

    On the server's web panel (ask its admins for the address), press Join server. The launcher sets up the modpack and starts the game.
