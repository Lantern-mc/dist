런처다운로드설치처음 시작하기사용법문제 해결변경 내역

변경 내역

버전별 다운로드는 다운로드 페이지에 있습니다.

0.2.11

현재 버전

고친 것

  • 서버의 프로필 코드와 모드팩 파일의 모드가 서로 다르면, 설치를 오래 기다리지 않고 바로 알려 줍니다. 어떤 모드가 다른지는 알림에 함께 나옵니다. 운영진에게 그대로 전해 주세요.
  • 서버 두 개를 거의 동시에 삭제해도 삭제가 실패하지 않습니다.
  • 지금 확인이 업데이트 직전에 Java 프로그램을 읽지 못해 업데이트를 미뤘을 때도 그 이유를 알려 줍니다.

0.2.10

0.2.9에서 바뀐 것도 함께 적었습니다.

고친 것

  • 게임을 켜는 중에 웹 패널의 서버 링크가 들어와도, 켜지고 있는 게임의 파일을 업데이트하지 않고 미룹니다.
  • 실행 중인 Java 프로그램의 정보를 읽을 수 없어 업데이트를 미룰 때(지금 확인 포함) 그 이유를 알려 줍니다. 게임이 아니라면 그 프로그램을 닫고 다시 시도하면 됩니다.
  • 서버를 삭제할 때 예전에 지운 같은 서버의 남은 파일 때문에 삭제가 막히지 않고, 빈 휴지통 폴더도 정리합니다.
  • 모드 개수는 같고 모드만 바뀐 팩 업데이트도 백그라운드 확인에서 업데이트 카드로 보여 줍니다.
  • 모드 파일 하나가 모드 ID를 여러 개 가져도 모든 ID로 같은 모드를 찾아, 같은 모드가 두 번 로드되지 않습니다.
  • 비정상적으로 긴 링크 요청은 읽지 않고 버립니다.

0.2.8

0.2.7에서 바뀐 것도 함께 적었습니다.

창과 안내

  • 웹 패널에서 서버 들어가기를 누르면 런처 창이 앞으로 나오고 그 서버가 선택되어 진행 상황이 보입니다.
  • 설정에서 게임이 켜졌을 때 런처 창을 어떻게 할지 고를 수 있습니다: 최소화(기본), 트레이로 숨기기, 그대로.
  • 설정에서 X 버튼을 눌렀을 때 트레이로 숨길지(기본) 런처를 끝낼지 고를 수 있습니다.
  • 런처가 직접 게임을 켤 때 뜨던 "준비됐습니다" 창이 더 이상 뜨지 않습니다.
  • 게임이 켜진 뒤 뜨는 질문(이전 프로필 정리 등)이 게임 위로 튀어나오지 않고 작업 표시줄에서 깜빡입니다.
  • 처음 시작 화면에서 Microsoft로 로그인과 CurseForge 받기 버튼이 가려지던 문제를 고쳤습니다.

CurseForge가 없을 때

  • CurseForge가 없는데 새 서버를 설치하려고 하면, 링크를 쓰기 전에 "CurseForge가 필요합니다" 창과 CurseForge 받기 버튼을 보여 줍니다.
  • 설치가 CurseForge 때문에 실패하면 알아볼 수 없는 오류 대신 이유와 받기 버튼을 보여 줍니다.
  • 이미 설치된 서버의 플레이는 CurseForge 없이도 그대로 됩니다.

설치와 업데이트

  • 모드팩 업데이트 중에 서버의 그림과 제목이 기본 그림으로 바뀌지 않습니다.
  • 모드팩이 어떤 경로로 적혀 있어도 플레이어의 세계(saves)는 덮어쓰거나 지우지 않습니다.
  • CurseForge 폴더 위치를 바꾼 뒤에도 이전 프로필 때문에 설치가 막히지 않습니다. 이전 프로필은 남기고 안내합니다.
  • 한 서버를 설치하거나 업데이트하는 동안에도 다른 서버의 작업이 막히지 않습니다.
  • 모드가 업데이트되면서 파일 이름이 달라져도 같은 모드(모드 ID)가 두 개 로드되지 않습니다. 팩의 모드와 ID가 같은 옛 파일은 .lantern-old로 이름이 바뀌어 게임이 읽지 않습니다. 지우지는 않습니다.
  • 런처의 서버 기록 파일이 갑자기 꺼져 깨져도 직전 기록으로 되살립니다.

서버 추가와 계정

  • 서버 추가에서 빈 폴더나 다른 서버가 쓰는 인스턴스를 고르면 바로 알려 줍니다. 고른 폴더가 그 서버의 모드팩이 아니면 추가를 되돌리고 새 링크로 다시 하라고 안내합니다.
  • 마인크래프트 계정을 바꾼 뒤에도 이전 계정의 화이트리스트 결과 때문에 빠른 입장과 게임 실행이 잠긴 채 남지 않습니다.
  • 화이트리스트 확인이 잠깐 실패해도 직전 결과를 유지해서 버튼이 켜졌다 꺼졌다 하지 않습니다.
  • 서버가 꺼져 있을 때 "꺼져 있음"이 한 번만 표시됩니다.
  • 설정의 업데이트 확인을 누르면 바로 확인하고, 확인하지 못했을 때는 "새 버전 없음" 대신 지금은 확인할 수 없다고 알립니다.
  • 설치나 실행이 실패했을 때 알림과 로그에 CurseForge 가져오기 코드가 보이지 않습니다.

0.2.6

0.2.1, 0.2.5, 0.2.6에서 바뀐 것을 합친 내용입니다.

모드팩 업데이트

  • 게임 실행을 누르면 먼저 서버 팩이 바뀌었는지 확인하고, 모드 목록이 그대로면 그 자리에서 적용한 뒤 실행합니다. 웹 패널에서 업데이트하라는 안내는 더 이상 뜨지 않습니다.
  • 지금 확인도 모드 목록이 같은 업데이트를 그 자리에서 적용합니다.
  • 모드가 바뀐 팩은 실행 전에 안내하고, 런처의 업데이트 버튼으로 설치합니다. 웹 패널을 열지 않습니다.
  • 바뀐 파일만 내려받아 업데이트가 빨라졌습니다.
  • 서버가 정한 리소스팩을 처음 한 번 자동으로 켭니다.
  • 업데이트 중 중지가 적용을 취소합니다. 다음에 실행하면 남은 파일부터 맞춥니다.
  • 중간에 끊긴 업데이트는 섞인 파일을 다시 받습니다. 서버에 닿지 않을 때는 그래도 실행을 묻습니다.
  • 팩이 바꾸지 않은 설정 파일(options.txt 등)은 업데이트해도 그대로 둡니다.
  • 팩 업데이트 뒤 이름이 바뀐 예전 모드·리소스팩이 남지 않습니다.
  • 게임이 켜진 뒤 이전 프로필 정리를 묻고, 서버를 지우면 이전 프로필도 지웁니다.
  • 삭제 허락이 없어도 이 PC에서의 설치가 막히지 않습니다. 이전 프로필은 남기고 안내합니다.

버튼과 안내

  • 서버가 꺼져 있거나 접속할 수 없으면 빠른 입장이 비활성화되고, 버튼 위에 그 상태가 표시됩니다. 게임 실행은 그대로 누를 수 있습니다.
  • 로그인한 계정이 화이트리스트에 없거나 승인 대기면 빠른 입장과 게임 실행이 둘 다 비활성화됩니다. 아직 확인되지 않았거나 로그인 전에는 막지 않습니다.
  • 업데이트 안내의 웹 버튼이 패널 첫 화면의 "서버 들어가기"로 안내합니다.

런처 업데이트와 안정성

  • 트레이 아이콘을 누르면 런처가 멈춰 아무것도 할 수 없던 문제를 고쳤습니다.
  • 런처 업데이트를 누르면 받는 중이라고 알리고, 다시 켜진 뒤 새 버전으로 업데이트했다고 알립니다. 받는 중에 다시 누르면 받는 중이라고만 알립니다.
  • 런처 업데이트가 확인 파일 형식 오류로 끝나지 않던 문제를 고쳤습니다.
  • 자체 업데이트가 끝나기 전에 런처를 다시 설치하면 켤 때마다 "이전 버전으로 되돌릴 수 없습니다" 알림이 뜨던 문제를 고쳤습니다.

0.2.0

새로 생긴 것

  • 홈 화면에 서버 공지 카드
  • 홈 화면과 왼쪽 목록에 서버 온라인/오프라인 상태
  • 게임을 켜기 전에 닉네임이 화이트리스트에 있는지 확인
  • 허용했지만 설치가 끝나지 않은 서버도 목록에 표시
  • 서버가 정한 제목 이미지를 홈 화면에 표시
  • 이름을 Lantern Launcher로 통일하고, 들어가는 버튼을 서버 들어가기로 정리

설치와 업데이트

  • 설치가 진행 상황을 보며 기다리고, 실패한 뒤에도 다시 시도할 수 있게 개선
  • 설치가 끝나지 않았는데 최신이라고 표시하던 문제 수정
  • 웹 패널의 링크로 게임을 켜면 바로 서버에 접속
  • 서버가 주소를 바꾸거나 지우면 이 PC의 멀티플레이 목록에도 반영
  • 서버가 거절한 이유를 “다시 연결”이라고만 하지 않고 구체적으로 안내
  • CurseForge가 파일을 열고 있어도 인스턴스를 읽고, CurseForge에서 모드를 따로 추가해도 모드팩이 불완전하다고 보지 않도록 수정

화면과 안정성

  • 팝업 뒤에 시스템 제목 표시줄이 비치던 문제 수정
  • 상태 카드의 버튼이 카드 밖으로 나가지 않고 다음 줄로 이어지도록 수정
  • 화면 배율을 바꾸는 중 창 메시지가 겹치면 오류가 나던 문제 수정

Lantern Launcher는 Lantern 서버에 들어가기 위한 Windows용 프로그램입니다. Mojang, Microsoft, CurseForge와 관련 없는 독립 프로젝트이며, Minecraft와 CurseForge는 각 권리자의 상표입니다.
